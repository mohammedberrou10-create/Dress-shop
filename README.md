# فساتين المحل: نظام تسيير محل فساتين الأعراس

نظام بسيط يساعد صاحب المحل على معرفة حالة كل فستان في أي لحظة: هل هو متاح أم مؤجَّر، وإن كان مؤجَّراً فمتى يستلمه الزبون ومتى يُرجعه.

## المميزات

- قائمة بكل الفساتين مع الصورة والحالة (متاح، مؤجَّر، متأخر)
- مدة الكراء وعدد الأيام المتبقية للإرجاع
- البحث باسم الفستان أو باسم الزبون أو هاتفه
- تنبيه عند تداخل حجزين لنفس الفستان
- سجل كامل لكراء كل فستان، مع السعر والعربون والمتبقي
- واجهة عربية من اليمين إلى اليسار، والعملة الدينار الجزائري
- نسخة احتياطية واسترجاع عبر ملف JSON

## الملفات

| الملف | الوصف |
|---|---|
| `index.html` | النموذج الأولي: صفحة واحدة تعمل في المتصفح، وتبقى بياناتها في الجهاز نفسه |
| `schema.sql` | هيكل قاعدة بيانات SQLite للنسخة ذات الخادم (فساتين، زبائن، كراء) |

## تشغيل النموذج الأولي

افتح `index.html` بأي متصفح. أو فعّل GitHub Pages من إعدادات المستودع (Settings ثم Pages ثم Deploy from a branch ثم `main` و `/ (root)`) فيصير للموقع رابط.

البيانات في النموذج الأولي محفوظة في الجهاز فقط، ولا تتزامن بين الأجهزة. استعمل زر «حفظ نسخة احتياطية» بانتظام.
